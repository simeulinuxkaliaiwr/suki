# Suki

Suki is a minimal image viewer built in C using SDL2. It is meant to be small, minimal and simple.

## Features:
- Open directories as arguments
- Optional title bars (-t/--title)
- Skips non-image files
- Supports dragging
- Supports zooming (by +/- and by the mouse wheel)
- Supports transparent PNG images
- Uses qsort to open files by an alphabetical order
